# Feuille de route — Club Ciné Tremplin

## Fait
- Fondations : postes multiples, rangs, supérieurs multiples, catégories, 45 postes
- Tâches (durée/phase/lien Drive), rapports, organigramme cliquable, fiches profil
- Idées + votes + passage automatique en projet approuvé, congés + notifications
- Comptabilité, bailleurs, contributions, dépenses, espace bailleur, mentor
- Discussions par espace, notifications internes, centre Modifications

## Phase 1 (faite, hors envoi d'emails)
- [x] Recherche de poste dans le formulaire membre
- [x] Suggestion automatique de rang (Assistant 1/2/3)
- [x] Champ « Projet(s) en cours » à la création d'un membre
- [x] Message de bienvenue interne + modèles configurables + son de confirmation
- [x] Notification aux supérieurs directs
- [x] Mot de passe oublié : messagerie membre ↔ producteur
- [ ] Envoi réel par email (bloqué : nom de domaine requis)

## Phase 2 (faite, hors emails)
- [x] Attribuer une tâche / Tâches reçues de mes supérieurs
- [x] Rapports « Destiné à » + Rapports reçus (messagerie)
- [x] Messages non lus (compteurs), rubrique Messagerie
- [x] Équipes : nom + poste, ajout/retrait

## Phase 3 (faite)
- [x] Organigramme dynamique haut-bas, projets par membre, description de poste
- [x] Raccourcis tableau de bord, avancement des projets
- [x] Participation aux projets (accepter/refuser avec commentaire obligatoire)

## Phase 4 (faite)
- [x] Idées non approuvées, auteur, réponses automatiques, délai 3 jours
- [x] Participation aux projets, numérotation romaine, loglines
- [x] Congés : choix du supérieur, conversation privée + discussion
- [x] Comptabilité : traçabilité, restrictions, contact bailleur = membre

## Phase 5 (faite)
- [x] Analyse par projet, impression PDF, Contrats, Feuille de service, Festivals

## Phase 6 (faite)
- [x] Mentors externes (lien + code), Vote anonyme + proclamation

## Phase 7 (faite)
- [x] Casting (formulaire public + sélection)

## Phase 8
- [ ] FR/EN, menu vertical gauche, mode clair/sombre, émoticônes

## Bloqué
- Emails automatiques : nécessite un nom de domaine possédé par le client
- WhatsApp automatique : nécessite WhatsApp Business API (niveau 1 par lien en attendant)

## Phase 8 — terminée
- [x] Langues FR/EN avec sélecteur et confirmation
- [x] Menu vertical à gauche avec émoticônes cinéma
- [x] Mode clair / sombre (préférence enregistrée)

## Phase B — Phases & statuts de projet (fait)
- [x] Phase et état (En cours / En pause / Terminé / Abandonné) sur chaque projet
- [x] Avancement réservé aux producteurs et au Directeur de production ; clôture réservée au Producteur général
- [x] Historique des phases + notification aux participants
- [x] Tableau de bord : phase, état et progression

## Phase C — Mots de passe & membres sortants (fait)
- [x] Modifications → « Comptes & mots de passe » : génération de mot de passe copiable, changement obligatoire à la prochaine connexion, désactivation / réactivation
- [x] Écran bloquant de changement de mot de passe
- [x] Chaque membre modifie son mot de passe depuis sa fiche (ancien + nouveau)
- [x] Comptes désactivés retirés de l'organigramme et des listes de sélection (données conservées)
- [x] Historique des postes occupés affiché sur la fiche profil
- [x] Retrait d'équipe : les tâches en cours passent « À réattribuer » et le chef d'équipe est prévenu

## Reste à faire
- [ ] Phase D — journal d'audit du Producteur général, relances automatiques 24 h
- [ ] Phase E — recherche globale, affichage mobile (menu repliable)
- [ ] Phase F — rubrique Vote indépendante (connexion dédiée, anonymat à deux tables)
- [ ] Phase G — vérifications de cohérence

## Phase D — Journal d'activité & relances (fait)
- [x] Rubrique « Journal d'activité » réservée au Producteur général : qui, quoi, quand, filtrable et imprimable en PDF
- [x] Aucun contenu de vote ni identité de votant enregistrés (seules ouverture/clôture des sessions)
- [x] Délai de décision et avance de rappel réglables dans Modifications
- [x] Relances automatiques aux décideurs avant échéance (idées, congés), sans doublon
- [x] Tâches en retard mises en évidence sur le tableau de bord

## Phase E — Recherche globale & mobile (fait)
- [x] Barre de recherche en haut : membres, projets, tâches, rapports, contrats, festivals, documents ; résultats limités par les droits, votes jamais indexés
- [x] Menu repliable (☰) sur téléphone

## Phase F — Vote anonyme (fait)
- [x] Espace de vote indépendant avec identifiant et code communs générés par session (copiables, lien copiable)
- [x] Projets du vote avec code obligatoire, modifiables uniquement avant l'ouverture
- [x] Verrouillage total à l'ouverture (confirmation demandée), clôture réservée au Producteur général
- [x] Deux registres séparés et inaccessibles : quota du jeton d'un côté, voix de l'autre — impossible de savoir qui a voté quoi
- [x] Règle des voix (2 par défaut) sur des projets différents, enregistrement au clic
- [x] Chiffres en direct, proclamation et impression PDF ; mentors et bailleurs exclus

## Phase E — Recherche globale & mobile (fait)
- [x] Barre de recherche générale (membres, projets, tâches, rapports, contrats, festivals, documents) respectant les permissions
- [x] Menu repliable ☰ sur petit écran, tableaux défilants

## Phase F — Vote anonyme (fait)
- [x] Session avec identifiant + code communs, copie du lien, verrouillage à l'ouverture
- [x] Deux registres séparés (quota / voix) : aucun lien possible entre une voix et une personne
- [x] Voix limitées, projets distincts, chiffres en direct, proclamation + PDF

## Phase G — Vérifications de cohérence (fait)
- [x] Bulles de discussion gauche/droite, liens centrés en bleu
- [x] « Ce que j'aime / ce que je n'aime pas » sur la fiche profil
- [x] Catégories Organisation / Artistique / Technique / Autres sur le tableau de bord, chacune avec sa discussion
- [x] Catégories de dépenses par phase (pré-production, tournage, post-production, communication & diffusion, administratif, autre)
- [x] Durée estimée sur chaque tâche, espace liens & documents partagé
- [x] Accès bailleur croisé (interrupteur), idées publiques notifiées aux producteurs et au scénariste, discussion par projet approuvé
